Welcome to Healthcare-analytics dbt project!

Description: A healthcare analytics project leveraging Snowflake for scalable cloud data warehousing, Amazon S3 for secure data storage, and DBT for transforming raw data into clean, modeled datasets. SQL is used throughout for querying and analysis to generate insights that support clinical and operational decision-making.

### Using the starter project

Try running the following commands:
- dbt run
- dbt test
